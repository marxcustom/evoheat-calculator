Marks Personal Pool Heating App - Aqua Technics

This calculator is for use in Australia. It stays closed until this device's location is confirmed inside Australia.

The button below asks the browser for this device's location once. The position is used only for that check. It is also sent once to BigDataCloud (api.bigdatacloud.net) to name the nearest suburb, or the locality if no suburb is available, in an access notification. Coordinates are not stored in this app and are not included in the notification.

A separate approximate city is looked up from the IP address by ipwho.is. That lookup does not grant access and is not the suburb.

If location is denied, times out, is unavailable, or cannot be confirmed in Australia, the calculator stays closed. You can try again. This check runs again each time the app is opened. It is a basic browser check, not a secure country lock. A copy saved on a device before this check was added can keep opening until that copy updates.
